# Site architecture

All ten routes are preserved: /, /about, /projects, /projects/guruku-gbayi-outreach, /gallery, /blog, /blog/from-purpose-to-action, /team, /partner, /privacy. No redirects are required for this checkpoint.

Homepage: mission hero → qualitative institutional focus strip → about narrative → programme-priority directory → documented outreach → vision statement → published journal story → get-involved pathways → existing footer with scoped appearance.

Partner/donor journey: homepage → documented outreach → partner enquiry or existing donation information. Volunteer journey: homepage involvement section → partner contact form; no vacancy or placement is promised. Research/journalist journey: programme context → outreach report/gallery → leadership and contact. Community visitor: homepage → programme information → direct contact.

Canonical URLs, structured-data updates, sitemap/robots, article dates, biography text, gallery and form integrations remain. New homepage tokens do not propagate to internal pages before approval. There is one article and one documented outreach; filters, search and pagination are not justified or introduced.
