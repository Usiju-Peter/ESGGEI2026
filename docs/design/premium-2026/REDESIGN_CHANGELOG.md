# Redesign changelog

## Homepage checkpoint

Dedicated branch `redesign/premium-2026` preserved the existing privacy correction and discovery notes. The first draft rebuilt the homepage in an original emerald/citrus editorial direction, with authentic photography, self-hosted Manrope/DM Sans, programme rows, outreach storytelling and meaningful involvement destinations. Homepage direction was provisionally approved by the user on 12 November 2026, subject to change. Production approval was not granted.

## Full-site implementation

Extended shared typography, colour, spacing, masthead, footer, buttons and focus treatments to all ten routes. Extracted common foundations from the homepage stylesheet. About now has numbered principles, documentary photography and a mission/vision spread. Projects has a ruled, anchored programme directory. Gallery has visible captions and an ordered editorial grid. Team uses open portrait compositions, existing short biographies and retained full-biography dialogs. Reports, articles, contact and privacy use the same system with page-specific layouts. Added article contents navigation and native sharing.

Added DocumentaryImage and ArticleShare. Added responsive image generation from original assets, including AVIF/WebP gallery derivatives and WebP portraits. Corrected portrait dimension metadata using the actual image files. Originals, URLs, factual prose, programme records, article dates, existing donations/contact details, consent controls and integration destinations remain. No new achievements, outcome counts, partners or testimonials were invented.

Removed unused AnimatedSection and ProgrammeCard exports. Kept React/Vite and source-managed publishing; no Next.js migration or new runtime dependency. Sharp and Playwright were already project development dependencies. Lighthouse is installed temporarily for measurement, and CI pins 13.6.0 without adding it to application dependencies.

Added 80-combination rendered QA, interactive-state checks, content-preservation evidence and a reproducible compressed local Lighthouse runner. Pull-request Lighthouse now measures its built revision; the weekly schedule continues to measure production. Image previews are generated by predev/prebuild and excluded from Git. Source images and licences remain committed.

## Validation refinements

Refined desktop headline wrapping, repaired a misleading gallery caption arrow, made dark-section focus visible at 9.25:1 contrast, allowed 44px footer targets in the homepage height budget, added article navigation and responsive images after measurements exposed image payload costs. Full-page gallery screenshots now explicitly decode and paint offscreen images before capture. One intermediate QA run was invalidated by a simultaneous rebuild and was discarded; verification uses a stable build.

No production branch, deployment credentials, domain settings or enquiry recipient was changed. The complete redesign remains a review build pending explicit production approval.
